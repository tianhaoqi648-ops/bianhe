# BGM 背景音乐文件

本目录用于存放抽辩仪式感 BGM 文件。请将以下 3 个 MP3 文件放置在此目录中：

## 文件清单

| 文件名 | 风格 | 建议时长 | 用途 |
|--------|------|----------|------|
| `ethereal.mp3` | 空灵 | 约 60s 循环 | 默认 BGM，用于大屏模式与揭晓动画 |
| `solemn.mp3` | 庄重 | 约 90s 循环 | 庄重场景（开幕式、颁奖） |
| `stirring.mp3` | 激昂 | 约 75s 循环 | 激昂场景（决赛、高潮环节） |

## 获取方式

- 推荐使用免版权 BGM（如 [freesound.org](https://freesound.org) CC0 资源）
- 文件大小建议 < 2MB
- 格式：MP3（兼容性最佳）

## 占位说明

当前目录仅含本 README.md 占位文件。未放置 MP3 时，代码会静默忽略并 Toast 提示"BGM 文件缺失"，不影响其他功能。

放置 MP3 后，BGM 将在以下场景自动播放：
- 进入计时器大屏模式（按 F）
- 抽辩揭晓动画开始时
